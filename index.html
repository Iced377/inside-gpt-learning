Embeddings are learned vectors. Their individual dimensions are not neat labels like “banking” or “grammar”. They are internal numerical features learned from training.

The same object keeps changing form

This is an important mental model: GPT is not swapping between a “language mode” and a “math mode”. Once text is encoded, the network continually transforms numerical representations.

2
Hidden processing: internal layers repeatedly transform those representations.
3
Output layer: the final representation is converted into scores for possible next tokens.

The handoff is the whole point.

The output of block 1 becomes the input of block 2. Block 2 performs its own attention and feed-forward calculations, producing yet another revised representation.

The numbers changed again. That revised representation would then move into the next transformer block. This repeated handoff is what “deep hidden processing” means.

Important: these numbers and percentages are teaching illustrations, not a trace from a production GPT. Real representations contain many more dimensions, and residual connections help preserve and combine information as it moves through the stack.
No neat job titles: it is misleading to say “layer 4 does grammar” and “layer 12 does finance”. Useful patterns are distributed across many components and layers.

Why the “bend”? If every layer only added and multiplied linearly, stacking layers would collapse into something equivalent to one large linear transformation. Non-linear activations let the network model much richer relationships. ReLU, GELU and gated variants are different ways to shape signals. GPT-style transformer families have commonly used smooth activations such as GELU, while newer architectures may use other gated variants.

The last hidden representation reaches the output layer

Now the model needs to turn a context-rich vector back into a decision over possible next tokens.

Every candidate token gets a score

The output layer projects the final representation onto the vocabulary. Those raw compatibility scores are often called logits.

A normalization step such as softmax turns those scores into a probability distribution.

You have just watched a forward pass. Forward propagation is simply the calculation from encoded input → hidden processing → output probabilities. During a forward pass, the model uses its current weights. The weights do not change yet.
ACT 2 OF 4Learn.How the model improves from error.
Learn from being wrong

A prediction is not learning. Correction is.

During pre-training, the text already contains the next token. That gives the model a target it can compare against its own prediction.

2

Backpropagation sends the error signal backward

The network calculates how its adjustable parameters contributed to the loss. An optimizer then nudges those parameters in directions expected to reduce future loss.

1 · Measure loss

How much probability did the model give the correct next token?

2 · Backpropagate

Use calculus to compute how each relevant parameter affected that loss.

3 · Update weights

The optimizer makes small numerical adjustments.

4 · Try more text

Repeat across enormous numbers of training examples.

Waiting
Important: learning is not supposed to memorize one sentence.

After many related examples, the model may become better at generalizing. For a new sentence such as “The customer applied for a ___”, “loan” may now receive more probability because the model has learned broader statistical patterns.
3

The clever part: the text creates its own training targets

This is why pre-training can scale so far. The model does not require a human to label the “correct next word” in every sentence.

The text itself supplies the answer. This is self-supervised next-token learning.
ACT 3 OF 4Scale.How a network becomes a large language model.
Become large

The basic learning loop stays familiar. The scale explodes.

A large language model repeats next-token learning over vast text collections using a very large transformer with many learned parameters and substantial computing resources.

Prepared data

Before training, datasets are collected, filtered, deduplicated and formatted. The exact recipe varies by model.

More text

Training spans huge token collections rather than one sentence.

More parameters

The model contains a very large number of adjustable learned values.

More compute

Training requires many high-performance accelerators and substantial infrastructure.

More repetition

The predict → compare → update loop runs again and again across training data.

Nothing magical suddenly appears at “large”. The same broad learning idea is being applied with a much more capable architecture, much more data and vastly more computation.

ACT 4 OF 4Assist.How a language model becomes useful in conversation.
Become an assistant

Pre-training creates a language model. Post-training shapes behavior.

A raw pretrained model can continue text, but useful assistants need additional training and evaluation to follow instructions, prefer helpful responses and behave more safely.

1 · Instruction / supervised tuningExamples demonstrate how to respond to prompts and follow requested formats.
2 · Preference learningHuman or AI-generated preference data can teach which responses are more desirable.
3 · Safety + evaluationTeams test capabilities, failure modes, policy behavior and robustness before deployment.

Finally: what happens when you actually chat with GPT?

Training and chatting are different modes. During ordinary generation, the model usually uses learned weights to predict tokens. It is not backpropagating and rewriting those weights after every word of your conversation.

The big picture

You now have the full story, end to end.

A GPT is not a database of prepared answers. It is a trained numerical model that repeatedly transforms context and predicts what token should come next.

1
Prepare + encode data

Training text is curated, tokenized and converted into learned numerical representations.

2
Transform context

Attention and feed-forward layers repeatedly rewrite representations.

3
Predict

The output layer scores possible next tokens and turns scores into probabilities.

4
Learn

During pre-training, the real next token supplies a target and loss drives weight updates.

5
Scale

Repeat across enormous data, model capacity and compute to create an LLM.

6
Post-train

Instruction, preference, safety and evaluation methods shape assistant behavior.
